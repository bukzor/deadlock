# Condition on the matchup

Every comparison carries an implicit "against whom". Situational items
exist precisely because the best option depends on the opponents, so
dominance and average strength are both functions of the matchup
distribution. Fixing the opponent slot is the same machinery with one
input held constant; averaging over observed opponents is the default.
The alternative, a matchup-free ranking, averages away the very logic
that explains the meta's situational picks.
