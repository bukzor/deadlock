# Every goal is a comparison

All five stated goals ask for a difference between alternatives, never
an absolute value. So the evaluator's errors cancel wherever they are
common to both sides: a simulator that is 20 percent wrong on absolute
time-to-kill can still order two builds correctly. This is what lets
the first simulator be crude (`../architecture.kb/engage-starts-trivial.md`).
