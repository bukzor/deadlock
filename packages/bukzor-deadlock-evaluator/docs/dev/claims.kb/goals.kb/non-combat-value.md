# Value that is not combat

Mobility, farm speed, vision and objective damage pay off in souls and
map state, not in a duel. A duel simulator alone values them at zero,
so an optimizer built on it would never buy them. The outcome schema
carries soul and objective channels so these items are priced
(`../architecture.kb/outcome-carries-non-combat-channels.md`).
