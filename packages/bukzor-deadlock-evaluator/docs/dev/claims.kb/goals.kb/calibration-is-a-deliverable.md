# Calibration is a first-class goal

"The simulator predicts in-game time-to-kill within x percent on a
stated sample" is a deliverable in its own right, because every
comparison inherits the simulator's error. The measurement is
the difference between simulated and measured outcomes over the same situations
(`../architecture.kb/measure-is-the-ground-truth-loop.md`).
