# Builds cluster into archetypes

Cluster builds by the direction of their StatVector into about a dozen
archetypes (gun carry, spirit burst, tank, support, and so on).
Matchups become an archetype-by-archetype matrix instead of a
combinatorial product, and the empirical side gets enough samples per
cell to fit anything.
