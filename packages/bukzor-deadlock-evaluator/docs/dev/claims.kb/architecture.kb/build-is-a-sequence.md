# Build is a time-indexed sequence

A Build is an ordered list of decisions (skill point, purchase, sell),
each stamped with the soul total at which it happened. Ordering comes
for free, and a final item set is a projection of it. The declined
alternative, Build as a set, cannot represent the orders public builds
actually are.
