# Order of work

Define the three schemas and the evaluator type. Then compile, a
trivial engage, a stub observe, and the five L4 operators. Every
application then runs end to end on day one, badly, and fidelity
improves by swapping evaluator implementations. Fit a macro value
function and a real replay parser only after that loop closes.
