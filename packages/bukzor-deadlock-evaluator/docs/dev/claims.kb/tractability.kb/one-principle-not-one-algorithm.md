# One principle, four tactics, no single algorithm

The explosions have four sources: combinatorial products of discrete
choices, sequential orderings, continuous state, and relational
interaction order. Each has a canonical tool and no one tool is right
for all four, which is why there is no single algorithm. What is
universal is the principle: exploit conditional independence to
factor, coarsen what will not factor, sample what will not coarsen,
and search only near observed data. The layer tower is that principle
applied once.
