# Factor by conditional independence

Win is independent of build given stats; fight outcome is independent
of team composition given participant stats. Each such assumption
deletes a product dimension from the joint. Where one fails, add a
single interaction term, never the whole joint back. This is
graphical-model reasoning and the source of the tower's savings.
