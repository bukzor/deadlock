# bukzor-deadlock-evaluator

Turns the extracted game data (the `bukzor-deadlock` package) into judgments
about builds: which skill point or item is better, why a popular build
is strong, which decisions are dominated, and eventually which build to
play. Nothing is implemented yet.

The design is a claim ledger, `docs/dev/claims.md` and `claims.kb/`.
Read `docs/dev/CLAUDE.md` first: it says how settled decisions, agent
proposals and open questions are told apart there.
