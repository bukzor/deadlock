# `public demo`: obtain one real public match demo

**Parent:** <../close-open-claims.md> (wave 1)

## Problem Statement

Goal: the seven local demos are bot matches, which may be lighter in
event density than human matches. Obtain one public ranked or
unranked match `.dem` so unit 002 can compare. Consumers: units 002
and 004.

Known routes, unverified: the in-game Watch tab downloads replays into
`game/citadel/replays/` (that directory exists and is empty); public
APIs (e.g. deadlock-api.com) list matches with `demo_url` fields pointing
at Valve's replay CDN (`.dem.bz2`). Prefer the API route since it needs
no game client; fall back to documenting the in-game steps for the
owner if every API needs a key we lack. Fetch only public match data;
never anything that needs the owner's credentials.

Store the demo under `data/replays/` (create it; it must be gitignored
like the rest of `data/` except `.do` files). Record how it was
obtained as a redo recipe `data/replays/<match-id>.dem.do` if the route
is scriptable; otherwise as prose in a new claim
`../claims.kb/tooling.kb/public-match-demos-source.md`
(`standing: agent`, `why:` the parser claim) that names the route,
the metadata the API exposes per match (rank bracket, patch, duration),
and any rate limit. Write that claim either way: the route is a fact the
design needs.

**Scope (only these files):** `data/replays/**`, the `.gitignore` line if
one is needed, `../claims.kb/tooling.kb/public-match-demos-source.md`,
this file.
