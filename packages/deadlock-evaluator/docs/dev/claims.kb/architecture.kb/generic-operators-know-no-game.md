# L4 operators know nothing about the game

compare, aggregate, attribute, search and pareto are written over the
evaluator type alone and never import a hero, item or stat name. This
is the discipline that makes paths open rather than close: every new
application is a composition, never new game logic. A game word in L4
is a defect.
