# One currency for skill points and items

Skill points are free but sequential; items cost souls. Comparing a
skill choice to an item choice, or either to a rotation, needs one
yardstick. The representation theory supplies it: win probability
added over the team-level game state
(`../representation.kb/win-probability-added.md`).
Without it the two stated comparison goals cannot share machinery.
