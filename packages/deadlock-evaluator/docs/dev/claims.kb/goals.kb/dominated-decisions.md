# Dominated decisions

The evaluator finds options that lose to some alternative in every
situation that occurs, and says why. Each one found shrinks the search
space every other goal runs over, so this goal is leverage for the
rest. Dominance is often conditional on matchup
(`matchup-conditioning.md`), and a claim of dominance must say over
which situations it holds.
