# Find where popular builds are wrong

The inverse of reproducing the meta: where the evaluator's synthesized
build beats the popular one, explain the gap stat by stat. This is the payoff
that justifies a mechanistic model over a purely empirical one, and
stating it keeps the capabilities built to disagree with the meta, not
only to agree with it.
