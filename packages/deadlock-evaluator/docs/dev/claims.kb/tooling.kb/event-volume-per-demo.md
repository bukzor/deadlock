# How many events does one Deadlock demo hold?

The half-million-per-match figure behind
`json-and-python-suffice-except-the-corpus.md` is extrapolated from
Dota-class demos, not measured. Parse one demo and count rows by
event type. This is the first measurement to make, because the store
choice rests on it.
