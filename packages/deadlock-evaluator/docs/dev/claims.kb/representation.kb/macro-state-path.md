# The macro state is about twenty numbers

Per-team souls, objectives taken, death timers, ultimate availability
and game time. A match is a path through this space, and transitions
are cheap to fit because the space is tiny. This is the slow layer of
`two-timescales.md` and the domain of `win-probability-added.md`.
