# Coarsen by quotient, and measure the loss

Archetypes for builds, breakpoint cells for stats, soul buckets for
time, bins for macro state: each replaces a space with its classes
under "same outcome for the question at hand". The quotient is valid
when within-class variance of that outcome is small, and that number
is measured, not assumed.
