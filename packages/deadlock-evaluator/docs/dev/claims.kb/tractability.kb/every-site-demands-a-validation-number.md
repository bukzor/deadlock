# Every approximation site demands a measured number

At each explosion site the checklist asks which tactic applies and
what measurement shows the approximation is good enough: within-class
variance for a quotient, residual for a truncation, sampling error for
a sample, calibration error for the simulator. An approximation
without its number is a guess wearing a method's name.
