# `vo lines`: one committed row per VO soundbite

**Parent:** <https:../2026-11-24-000-vo-transcripts.md> (wave 2)

## Problem Statement

Build the per-soundbite table that the transcript unit (004) fills in. For
every VO sound event of every hero it needs the event name, the hero, the
audio path or paths, each audio file's CRC32 (004's cache key), and the
caption text in every locale that has one.

Inputs:
- `soundevents/vo/generated_vo_hero_*.vsndevts_c`, from unit 001's exploded
  tree: event name to `vsnd` paths. Decompile them with VRF.
- Captions are **loose files outside the paks**:
  `$DEADLOCK_HOME/game/citadel/resource/localization/citadel_generated_vo/citadel_generated_vo_<lang>.txt`,
  UTF-8 with a BOM, KeyValues `"lang" { "Tokens" { "<token>" "<text>" } }`,
  where the token is readable, e.g. `patron_female_ally_yamato_start_01_announcer`.
  Some locales are stubs of about 60 bytes. Parse them with the `vdf`/
  keyvalues library the repo already uses for localization, if there is one
  (see `bukzor-deadlock-lookup`'s `names.py`). The `.dat` that
  `data/manifest.jsonl` lists comes from a stale build, and
  `formats.kb/vsnd.md` ("no VO caption file in the paks") is true of the
  paks only. Correct that sentence so it points at the loose files.
- `data/manifest.jsonl` is stale against build 6864. Don't count from it.

For you to settle and report:
- The table's shape (wide by locale, or long), its path under `data/`, and
  whether it is committed. It is a transformative join, so the
  commit-diffable decision probably says yes. Shape it for 004's per-clip
  loop.
- How caption tokens map to event names (is the token the event name?), and
  how many stay unmatched in each direction.
- **The question the plan turns on:** for Yamato's lines, does any
  non-English locale carry a real translation instead of its own
  "[Speaks Japanese]"? Give counts per locale and quote three examples.

**Scope (only these files):** new `src/bukzor_deadlock/` module(s) for
captions and soundevents (+ tests), new `.do` files and the committed table
under `data/`, a `.gitignore` exception for it, new
`docs/dev/formats.kb/vo-captions.md` (the caption files: location,
encoding, token naming, per-locale coverage), the one sentence in
`docs/dev/formats.kb/vsnd.md` named above, the repo `CLAUDE.md`'s "Look facts up" paragraph (one
clause naming the new table), this file.
