# `vsnd probe`: what a VO sound resource carries

**Parent:** <https:../2026-11-24-000-vo-transcripts.md> (wave 1)

## Problem Statement

The plan needs an English transcript for each Yamato VO soundbite. Before
we pay for ASR, find out what the game ships inside the sound files. The
answers decide unit 004.

Questions:
1. Does a VO `vsnd_c` embed any text: a sentence, words, phonemes or
   lip-sync data? Source 1 WAVs carried a VDAT sentence chunk, so Source 2
   might carry something similar. Check what VRF exposes and also scan the
   raw blocks yourself. Check both a Yamato line and an English-speaking
   hero's line.
2. What codec, sample rate and channel count do the clips use, and what
   does VRF decode them to?
3. Of the 3163 Yamato `vsnd*` paths in `data/manifest.jsonl`, how many are
   VO, and what is their total duration? Unit 004 sizes its CPU budget from
   this. Header durations are enough; don't decode them all.

This is an investigation, so work in `trash/vo-transcripts/002/` with the existing
`extract.py`/`s2v` path. Unit 001 is building the general VPK explode in
parallel, so don't build extraction infrastructure. Archive any script the
doc cites into `docs/dev/probes/`.

**Scope (only these files):** new `docs/dev/formats.kb/vsnd.md` (the
format findings), a line for it in `docs/dev/formats.kb/CLAUDE.md` if that
file indexes its entries, `docs/dev/probes/vsnd-*`, this file.
