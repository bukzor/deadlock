# `asr runner`: build the ASR job and start it in the background

**Parent:** <https:../2026-11-24-000-vo-transcripts.md> (wave 4)

## Problem Statement

Build the ASR side of the design doc, then start the full Yamato run
detached and hand back without waiting for it. Unit 006, the fix-up pass,
consumes the ASR ledger, and can start on its rows while the run is still
going.

Build:
- **Audio:** a redo target that decompiles the in-scope clips' `vsnd_c` to
  MP3 under `data/vo/audio/`, using VRF `-d` (see `formats.kb/vsnd.md`).
- **Model:** a redo target that fetches the model 004 recommends into
  `data/tools/whisper/`.
- **The job:** a Python module that writes `transcripts/asr/<hero>.tsv` as
  the design doc says. It uses the batching and splitting method 004
  validated, `-l ja`, `nice -n 19`, and 004's thread layout within the
  4-thread budget. It is kill-safe and resumable. Test its pure parts
  (pending set, the clip-offset split, ledger merge) red first; the
  whisper call itself stays a thin, untested shim.
- **The view:** a redo target for `data/vo/japanese.tsv` that joins
  `lines.tsv`, the ASR ledger and `transcripts/fixups.tsv`, which may not
  exist yet. It is committed.
- **Wiring:** add `data/vo/lines.tsv` and `data/vo/japanese.tsv` to
  `data/all.do`'s `committed` list (for `redo-adopt`) and to its
  `redo-ifchange`.
- **Script:** `bin/asr-yamato` (or a better name), a ≤50-line shim that
  starts the job in tmux session `asr`.

Then start the run with that script, check that the first rows land, and
hand back. In your report, say how to watch it, how to stop it, and your
estimate of when it finishes.

Don't fix the pre-existing re-provisioning of `Source2Viewer-CLI.d` on
every build. If it gets in your way, say so in your report.

**Scope (only these files):** new `src/bukzor_deadlock/vo_asr*.py` (+
tests), new `.do` files under `data/vo/` and `data/tools/whisper*`,
`data/all.do`, `.gitignore` (if needed), `transcripts/asr/` (the ledger the
job writes; commit what has landed by hand-back), `bin/asr-*`, the
"Look facts up" paragraph of the repo `CLAUDE.md` (one clause for
`data/vo/japanese.tsv`), this file.
