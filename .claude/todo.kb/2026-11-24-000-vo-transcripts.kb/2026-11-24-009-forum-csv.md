# `forum csv`: the file the owner publishes on the Deadlock forum

**Parent:** <https:../2026-11-24-000-vo-transcripts.md> (wave 8)

## Problem Statement

The owner will post this CSV on the Deadlock forum. It suggests replacement
captions for every "Speaks <language>" line. Readers are players and
modders: some will open it in Excel or Google Sheets, and some will grep it.

Build it as a redo target, `data/vo/forum.csv`, derived from
`data/vo/foreign.tsv` and `data/vo/lines.tsv`. It is local only, not
committed: it holds nothing the committed view doesn't. Columns, in this
order:

| column | content |
|---|---|
| `hero` | the display name (Yamato, Ivy, Lady Geist, Bebop), through the lookup package |
| `caption_token` | the event name, which is the key in `citadel_generated_vo_english.txt`, so a modder or Valve can apply a fix directly |
| `file` | the `vsnd` path |
| `current_caption` | what the game shows today ("Speaks Japanese") |
| `suggested_text` | the replacement, in the spoken language |
| `suggested_translation` | the English translation |
| `note` | empty, or a plain-English note for the doubtful rows (from `doubt`) and owner-heard rows ("verified by ear") |

The owner's proposed raw-whisper column is left out on purpose. It mostly
repeats `suggested_text` with ASR errors, and for forum readers it would be
noise. Where it matters, in the doubtful rows, `note` says what was heard.
This is the coordinator's recommendation, and the owner can still veto it.

Coordinator amendment after 008: 70 rows are clips with no caption at
all (`lang` = `auto`; 69 English, one Spanish). They belong in the CSV, as
missing captions are a fix in their own right. `current_caption` is
empty, and `note` says "no caption in game". Put the spoken language in
`note` only where it isn't the one the caption names. Ivy's two "Tengu"
pings: `note` says she says her pre-rename name.

Use RFC 4180 quoting and UTF-8 with a BOM (Excel needs the BOM to show
Japanese correctly). Sort by hero, then `caption_token`. Small pure
function plus a test, red first.

**Scope (only these files):** new `src/bukzor_deadlock/vo_forum.py` (+
`_test.py`), `data/vo/forum.csv.do`, this file.
