# `caption mod`: our captions as an installable mod, and as diffs for Valve

**Parent:** <https:../2026-11-24-000-vo-transcripts.md> (wave 9)

## Problem Statement

Turn `data/vo/foreign.tsv` into two artifacts, both rebuilt by redo on every
patch and local only (gitignored, nothing under `data/` committed):

1. **A mod:** one VPK holding
   `resource/localization/citadel_generated_vo/citadel_generated_vo_<locale>.txt`
   for each of the 17 real locales (every file in the game's
   `citadel_generated_vo/` over 1 KB; the 12 others are 60-byte stubs).
   Each file holds **only the tokens we change.** deadlock-mod-manager
   merges localization per token and restores the rest. The plan records
   why, and why a full-file copy is worse.
2. **Diffs for Valve:** for each locale, a unified diff from Valve's file to
   Valve's file with our tokens substituted in place. Keep Valve's
   encoding, BOM, CRLF and token order.

The caption for a row, in locale L (owner's styling ruling, in the plan):
- the `replacement`, then `<br>`, then the translation in brackets:
  `奇怪な生き物だ。<br>[A bizarre creature.]`. The bracket line is
  dropped when L is the spoken language (ja → japanese; es → spanish and
  latam; fr → french), and for English speech in the english locale.
  `<br>` is what the game's other localization uses (1050 uses in the
  English files; no `<cr>` or `\n`). The owner's in-game test confirms
  that it renders in captions. Keep the separator one constant.
- The translation comes from `transcripts/locale-translations.tsv`
  (columns `translation locale text by`, keyed by foreign.tsv's English
  `translation`; written by unit 012, possibly absent or partial). Where
  no row exists, use the English translation. The mod is valid at every
  stage of 012.
- Include the rows with no caption today (`lang` = `auto`, or an empty
  English caption in `data/vo/lines.tsv`): the token is the event name, so
  adding it should make a caption appear. Exclude
  `transcripts/caption-corrections.tsv` entirely (owner ruling: held
  apart).
- Escape any `"` and `\` the way Valve's files do.

**Packing:** find out what writes a VPK that Deadlock loads. Read only:
the python `vpk` package already in the environment (it writes v1; does
Source 2 load v1?), deadlock-mod-manager's own writer (it builds
`pak01_dir.vpk` overlays; clone at
`~/repo/github.com/deadlock-mod-manager/deadlock-mod-manager`, untrusted,
read only and never run). Prefer what we already have. If nothing works
without new tooling, stop after the text files and diffs, and put the
packing question in Open Questions.

**Verify:** parse every generated file back with the repo's KeyValues
reader. Check that its tokens are a subset of the game file's plus the
uncaptioned events, and that every foreign.tsv row is present in every
locale. Write a durable reference doc at
`docs/dev/formats.kb/caption-mod.md`: layout, styling rules, how
deadlock-mod-manager installs it (from the plan's findings), and how to
install locally ("Add Local Mod").

**Scope (only these files):** new `src/bukzor_deadlock/vo_mod.py` (+
`_test.py`; split if it nears 300 lines), new `data/mod/*.do` targets,
`docs/dev/formats.kb/caption-mod.md`, this file. Scratch:
`trash/vo-transcripts/011/`. Don't touch unit 012's ledger or 014's
`vo_forum.py`.
