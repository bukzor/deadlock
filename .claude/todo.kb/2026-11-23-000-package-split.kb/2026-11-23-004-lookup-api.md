# `bukzor-deadlock-lookup`: typed game data, by key or English name

**Parent:** <https:../2026-11-23-000-package-split.md> (wave 3, beside unit 003)

## Problem Statement

Build the lookup API inside the scaffold that unit 002 left in
`packages/bukzor-deadlock-lookup/`. Unit 005 then moves the damage modules
and vis onto it, and unit 006 the Crimson Slash data. Shape the API for
those consumers; don't edit any of them here.

What the consumers do today, and what the API replaces:

- **vis `queries.py`** (`load_data`, `GameData`, `listed`, `_kit`): loads
  `heroes.json`, `abilities.json` and `heroes.tsv`, plus the localization
  from the install. It lists the live, playable heroes with their display
  names, and a hero's kit by slot.
- **damage modules**: about 30 `dig(tree, key, "m_...")` calls on raw vdata
  keys. There are three private float parsers of `m_strValue`
  (`guns._num`, `melee._num`, `casts._number`), spirit scaling read from
  `m_subclassScaleFunction`, `m_bIsAbilityDamageProperty`, per-level hero
  stats (`boons`) and gun profiles. Read the modules for the full list.
- **Crimson Slash data**: names items in English ("Tankbuster", "Mystic
  Reverb"). It needs each item's key, tier, cost and slot, so that
  equal-cost swaps can be asserted. English item names are in the install's
  `citadel_gc_mod_names` localization (for example, Tankbuster is
  `upgrade_magic_shock`); hero and ability names are in the files
  `names.load_tokens` already reads.

Requirements:

- **Loading:** data is read once per process, lazily. Importing a consumer
  stays cheap and needs no data; vis reads `data/` at its first query.
- **Tests:** the lookup can be built from in-memory trees, so tests can
  pass synthetic data the way vis's `conftest.py` does today.
- **Name resolution:** a lookup takes a key or an English name. An unknown
  or ambiguous name raises, and the message names the near candidates.
  Names are resolved per kind (hero, ability, item), never across kinds.
- **Types and deps:** typed under the root's pyright (`typeCheckingMode =
  "all"`), Python 3.12, and no dependency beyond `bukzor-deadlock` and the
  stdlib. If you need another, stop and report: the lock belongs to unit 003
  this wave.
- **Keep `names.py` working:** unit 002 put the localization helpers in
  `names.py`, and damage and vis call them. Keep those functions working,
  even as thin delegates to the new API. Unit 005 removes whatever is then
  unused.
- **Tests:** beside each module (`{module}_test.py`). Include at least one
  test against the real `data/` tree and install: Tankbuster's key and its
  3200 cost, and Yamato's Crimson Slash key `citadel_ability_healing_slash`.

**Scope (only these files):** `packages/bukzor-deadlock-lookup/` (except its
`pyproject.toml` dependencies), and this file
