# Rename: `deadlock` to `bukzor_deadlock`, the evaluator to `bukzor-deadlock-evaluator`

**Parent:** <https:../2026-11-23-000-package-split.md> (wave 1, alone)

## Problem Statement

Every later unit builds on the new names, so this is a pure rename and
nothing else: no behavior change and no refactor.

- Root distribution `deadlock` becomes `bukzor-deadlock`, and its import
  package `src/deadlock/` becomes `src/bukzor_deadlock/`.
- `packages/deadlock-evaluator/` becomes `packages/bukzor-deadlock-evaluator/`,
  its distribution `bukzor-deadlock-evaluator`, its import package
  `src/bukzor_deadlock_evaluator/`. Its `docs/` move with it.
- Every live reference follows: Python imports, `python -m deadlock.X`, and
  `$root/src/deadlock/...` dependency paths in `*.do` files and `bin/`;
  `apps/vis/server` (imports, `RELOAD_DIRS`, its `pyproject.toml` source
  `deadlock = { path = ... }`); `tests/`; docs, claims, ideas and
  `.claude/todo.md` wherever they name the package, a module path or the
  evaluator's directory. Relative links into the evaluator's directory, for
  example from `apps/vis/docs/dev/claims.kb/`, must still resolve.
- Out of scope: `src/dllscan/` keeps its name (unit 003 moves it). Frozen
  records keep their text (see this kb's `CLAUDE.md`). Do not edit
  `.claude/todo.kb/2026-11-23-000-package-split.md` or this kb, apart from
  your own sections of this file.

Find references with `git grep` (for example `-e '\bdeadlock\.' -e 'from deadlock'
-e 'import deadlock' -e 'src/deadlock' -e 'deadlock-evaluator'
-e 'deadlock_evaluator'`), then read each hit: prose about the game stays.
`uv lock` in the root and in `apps/vis/server` regenerates both locks.

Extra check, on top of the kb's: `redo` from the repo root rebuilds `data/`,
and afterwards `git status --short -- data/` shows no committed file
changed. The rename invalidates every view, so expect a full rebuild. If the
Windows-host DLL facets (`data/dlls/`) can't run here, say so and check
everything else.

`src/bukzor_deadlock/`, `packages/deadlock-evaluator/` →
`packages/bukzor-deadlock-evaluator/`, `apps/vis/server/` (`pyproject.toml`,

`.claude/todo.md`, `.claude/ideas.kb/`, and this file
