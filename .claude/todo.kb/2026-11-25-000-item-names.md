# Item names: the in-game name beside each item codename

**Method:** Skill(subagent-handoffs); a sub-agent does each unit, briefed in
`2026-11-25-000-item-names.kb/`

## Problem Statement

The owner, 2026-11-25: "attach the in-game readable names to the items.
Currently 'Lucky Shot' is represented as 'upgrade_critshot', with no
indication of the in-game name."

Coordinator survey: the names are in the install's
`game/citadel/resource/localization/citadel_gc_mod_names/citadel_gc_mod_names_english.txt`
(`"upgrade_critshot" "Lucky Shot"`). Heroes already get their names this way:
`heroes.tsv` has a `name` column, read through `loc.py` from
`paths.hero_names_loc`.

## Success criteria

- `data/gamedata.tsv/items.tsv` has a `name` column, and
  `grep 'Lucky Shot' data/gamedata.tsv/items.tsv` finds `upgrade_critshot`.
- `./bin/shell pytest` and `./bin/shell pyright` are clean.
