# The live loop shows one page URL, and the API never serves a stale page

**Parent:** <https:../2026-11-18-000-vis-app.md> (review round 2)

## Problem Statement

After unit 014, the user opened `http://127.0.0.1:8788/`, the last URL in
`bin/serve`'s output (uvicorn's banner), and got a `client/dist` built before
units 016–017: the old page, against the new API. The coordinator has moved
that `dist` to `trash/stale-dist/`; this unit makes the trap impossible.

**Goal:** under `bin/serve`, the only page is Vite's, and the only URL the
output offers is Vite's.

**Decided:**

- `vis-server serve --reload` never mounts `client/dist`: in the live loop, Vite
  serves the page. `vis-server serve` without `--reload` keeps today's
  behaviour (a single process serving a built `dist`).
- With no page mounted, `GET /` answers 404 with one `{"error"}` line saying
  this is the API only, and that the page is the URL `bin/serve` printed.
- `bin/serve`'s output names no URL but the page's. For example, quiet
  uvicorn's "running on" banner (`--log-level warning`, or uvicorn's own option
  for it) while keeping its reload and error lines, and print the "open …" line
  after both children are up, not before.

**Scope:** `apps/vis/bin/serve`, `apps/vis/server/src/vis_server/{http,__main__}.py`
and their tests, `apps/vis/README.md` if its wording changes, and a note in
`apps/vis/docs/dev/claims.kb/serve-live-reload.md`.

**Don't** stop the coordinator's running `bin/serve` (5173/8788); use other
ports for your own proof runs.

## Steps

- [x] `http.app(client=None)` and `live()` factory; `GET /` 404 `{"error"}` when no page; `serve --reload` uses `live`.
- [x] `NoBanner` log filter in `__main__` (reload only); `bin/serve` waits for both ports, then prints the "open" line; Vite `--clearScreen false`.
- [x] Tests; README and `serve-live-reload.md` notes.

## Decisions

- Banner removal is a logging filter, not `--log-level warning`, which would also drop the reload lines. Non-reload `serve` keeps its banner (it is the page URL there).
- The 404 text is also shown when a non-reload server has no build; "the URL bin/serve printed" is slightly off there (accepted).
- `--clearScreen false` so Vite's clear cannot erase the "open" line.
