# UX round, client side: cumulative line, per-kind controls, URL state, hover

**Parent:** <https:../2026-11-18-000-vis-app.md> (review round 2)

## Problem Statement

Implement the client half of unit 015's findings, as the amended design's
"Client view" states them. Unit 016 changes the server in parallel. Code
against the design's protocol: measure lines gain a `label`, and fall back to
`name` while the server lacks it.

- **Finding 2: cumulative damage.**
  - Add a step line on a right-hand axis, and a dashed line at `hp` when it is
    set.
  - Keep the bars, labelling their axis "damage per hit".
  - Give the line and the bars distinct but harmonious colours, and make it
    clear which axis belongs to which.
- **Finding 4: a width caption per `kind`.**
- **Finding 5: per-kind controls.** Show only the parameters that apply to the
  ability's `kind`. A placeholder reads as a default ("default 10"), never as
  an entered value. A blank `horizon` means the server's default.
- **The user's amendment: two horizon inputs.** The user asked for "two
  mutually-updating inputs: seconds (as currently) and \"x period\" (default
  2) -- so by default we see two \"full cycles\" of damage".
  - The server's new first line, `{"kind": "cycle", "period", "downtime",
    "horizon"}`, gives the period and the horizon it used.
  - Editing either input updates the other.
  - When the cycle has no period, disable the periods input.
  - Code against the protocol: unit 016 adds that line in parallel.
- **Finding 6, part one: the selection lives in the URL.** Reloading or
  sharing the page restores it. Comparison overlays are deferred.
- **Finding 8: hover.** The tooltip follows the pointer anywhere on a bar,
  using `Plot.pointerX` or a tip on the rect.
- **Finding 10: title.** Rename it "Damage timeline".
- **Measures table.** Show `label`, value and unit, with the check text kept
  but visually secondary.

Apply dataviz judgement yourself; the skill is disabled for model invocation.

cumulative series.

  CLAUDE.md about `pnpm`).

  8787. Save them in `trash/017/`.
